# SOFT APP — Support | الدعم

**SOFT APP** is the companion (view-only) mobile app for subscribers of **Soft System — Financial Management**.

- **Need help / تحتاج مساعدة؟** Open an issue here: [New support request](https://github.com/husseinzwain/soft-app-support/issues/new)
- **Privacy Policy / سياسة الخصوصية:** [PRIVACY.md](./PRIVACY.md)

## بالعربي
تطبيق «SOFT APP» هو التطبيق المرافق (للعرض فقط) لمشتركي «نظام سوفت للإدارة المالية».

- إذا عندك مشكلة أو استفسار: افتح طلب دعم من زر **Issues** أعلاه، أو تواصل مع إدارة مكتبك المشترك بالنظام.
- حسابات الدخول تُنشأ من قبل مدير المكتب المشترك — التطبيق لا يوفر تسجيلاً ذاتياً.
